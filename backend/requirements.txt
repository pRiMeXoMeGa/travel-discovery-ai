# ── MCP server (WS2) ─────────────────────────────────────────────────────────
# Pinned to 2.14.* deliberately. PyPI now serves fastmcp 3.x, and the official
# `mcp` SDK is at 2.0 requiring starlette 1.6 — a major jump that FastAPI
# 0.115 does not accept. 2.14 resolves against starlette 0.46 and mcp 1.29.
#
# It is NOT free: it forces httpx 0.27->0.28, pydantic 2.9->2.13 and
# uvicorn 0.32->0.52, which is why those three pins above are ranges rather
# than the original exact pins. The upper bounds are deliberate — they pin the
# versions this combination was actually verified against, so a future resolve
# cannot silently drift onto an untested httpx or pydantic major.
fastmcp==2.14.*
